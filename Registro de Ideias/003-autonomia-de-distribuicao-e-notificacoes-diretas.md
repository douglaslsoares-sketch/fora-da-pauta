# Ideia 003 — Autonomia de distribuição e notificações diretas

## Visão

O Fora da Pauta deve buscar, desde o início, construir uma relação
direta com seus leitores.

O próprio site será o espaço principal de publicação, leitura,
acompanhamento e circulação das edições.

A estratégia não deverá depender da construção de audiência
em redes sociais de terceiros.

## Princípio de autonomia

O objetivo é reduzir a dependência de:

- algoritmos de redes sociais;
- mudanças de regras de plataformas;
- interesses comerciais de terceiros;
- decisões de moderação externas;
- necessidade de possuir seguidores em outras redes para que
  o conteúdo chegue aos leitores.

Ter infraestrutura própria não significa independência absoluta.

Serviços de hospedagem, e-mail, WhatsApp, Telegram, pagamentos
e outros provedores também possuem suas próprias regras.

O objetivo é reduzir principalmente a necessidade de uma rede
social externa funcionar como intermediária obrigatória entre
o Fora da Pauta e seus leitores.

## Estratégia de circulação

A estratégia principal deverá priorizar o compartilhamento direto
entre pessoas.

Fluxo desejado:

**edição compartilhada → nova pessoa lê → escolhe acompanhar →
recebe a próxima edição → compartilha com outras pessoas**

O leitor passa a ser um dos principais meios de circulação
do Fora da Pauta.

## Compartilhamento em cada edição

Cada edição deverá facilitar o compartilhamento direto,
especialmente no celular.

Meios prioritários:

- WhatsApp;
- Telegram;
- compartilhamento nativo do celular;
- copiar link.

Outros canais poderão ser adicionados quando fizer sentido.

## Receber a próxima edição

A pessoa poderá optar por receber uma notificação quando uma
nova edição for publicada.

Ela poderá escolher o meio pelo qual deseja ser avisada.

Canais inicialmente considerados:

- e-mail;
- WhatsApp;
- Telegram.

A pessoa deverá fornecer apenas os dados necessários ao canal
escolhido.

Não deverá ser necessário criar uma conta apenas para receber
as notificações.

## Convite dentro da própria edição

O convite para receber novas edições deverá existir dentro da
própria página que a pessoa está lendo.

Ela não deverá precisar:

- voltar para a página principal;
- procurar uma área de cadastro;
- navegar por outras páginas;
- criar uma conta.

Exemplo:

**Quer receber a próxima edição?**

Escolha como prefere ser avisado:

**E-mail · WhatsApp · Telegram**

O principal local desse convite deverá ser depois do conteúdo,
quando a pessoa já terminou a leitura.

Outras aparições discretas poderão ser avaliadas, desde que não
interrompam a experiência de leitura.

## Relação com redes sociais externas

O projeto não deverá depender de Instagram, X, Facebook ou outras
redes como centro de sua audiência.

O compartilhamento direto entre leitores deverá cumprir grande
parte da função de descoberta do projeto.

Canais externos poderão eventualmente ser utilizados, mas não
deverão ser necessários para que um leitor acompanhe o Fora da
Pauta.

Princípio:

**O conteúdo é publicado no Fora da Pauta.**

**O leitor escolhe acompanhar o Fora da Pauta diretamente.**

**A audiência cresce de pessoa para pessoa.**

## Uso dos dados de contato

Os dados fornecidos para receber notificações deverão ser usados
apenas para a finalidade informada.

Princípios:

- não vender listas de contatos;
- não repassar contatos sem base adequada;
- não enviar mensagens excessivas;
- permitir saída simples;
- respeitar o canal escolhido;
- coletar somente o necessário.

## Final de cada edição

O final de cada edição deverá funcionar como uma pequena central
de continuidade da relação com o leitor.

Deverá reunir, de maneira simples:

1. convite para receber a próxima edição;
2. opções de compartilhamento;
3. link para ver todas as edições;
4. link para apoiar financeiramente o projeto.

## Link — Ver todas as edições

Deverá existir um link como:

**Ver todas as edições**

Esse link levará para a página principal ou para um arquivo de
edições já publicadas.

Objetivos:

- permitir descobrir outros temas;
- facilitar acesso ao histórico;
- transformar uma leitura isolada em exploração do acervo.

## Link — Apoiar o Fora da Pauta

Também deverá existir um caminho como:

**Apoie o Fora da Pauta**

Esse link levará para uma página de contribuição voluntária.

Modelo atual pensado:

**R$ 10 por ano**

com renovação anual automática.

A página deverá informar claramente:

- que a contribuição é voluntária;
- que o conteúdo continua aberto;
- que a cobrança é anual;
- que existe renovação automática;
- que é possível cancelar quando quiser.

Exemplo:

**Gostou do Fora da Pauta? Ajude a manter o projeto.**

Contribuição voluntária: R$ 10 por ano.

Renovação anual. Cancele quando quiser.

## Gerenciar ou cancelar contribuição

A página de apoio deverá oferecer acesso fácil a:

**Gerenciar assinatura**

Essa área deverá permitir:

- consultar o status;
- verificar a próxima renovação;
- cancelar a renovação automática;
- cancelar a assinatura;
- atualizar dados de pagamento quando necessário.

A pessoa não deverá depender de atendimento manual para cancelar.

A opção deverá permanecer acessível sempre que o apoiador precisar.

## Relação com as edições

A lógica de publicação pretendida é:

**uma edição por vez, cada edição dedicada a um tema.**

A referência inicial é de pelo menos uma nova edição por mês.

A notificação levará o leitor diretamente para a nova edição.

## Status

Ideia com potencial de implementação já na fase atual.

Na reconstrução mobile-first das páginas de edição, prever desde
o início:

- compartilhamento direto;
- convite para receber a próxima edição;
- escolha do canal de notificação;
- link para todas as edições;
- link para apoio voluntário;
- acesso ao gerenciamento da contribuição;
- experiência simples, sem exigir conta apenas para acompanhar.
