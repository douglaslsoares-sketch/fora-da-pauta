# Registro de Ideias — Fora da Pauta

Esta pasta preserva decisões, hipóteses e ideias para possíveis
evoluções do projeto Fora da Pauta.

O registro de uma ideia não significa implementação imediata.

A finalidade desta pasta é impedir que ideias importantes se
percam e permitir que sejam retomadas no momento adequado.

2. [Rede social aberta com identidade verificada](002-rede-social-aberta-com-identidade-verificada.md)

3. [Autonomia de distribuição e notificações diretas](003-autonomia-de-distribuicao-e-notificacoes-diretas.md)

## Regra

Quando uma ideia for alterada ou amadurecida, o arquivo existente
deverá ser atualizado em vez de criar versões contraditórias.

O histórico das mudanças ficará preservado pelo Git.
